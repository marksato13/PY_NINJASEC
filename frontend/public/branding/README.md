# Branding Assets Guide

Usa esta carpeta para organizar las imagenes oficiales del frontend de `NinjaSec`.

## Estructura

- `branding/logos/`
- `branding/heroes/`
- `branding/banners/`
- `branding/avatars/`

## Recomendaciones por carpeta

### `branding/logos/`

Aqui van los logos principales de la empresa.

Archivos sugeridos:

- `logo-primary.png`
- `logo-light.png`
- `logo-dark.png`
- `favicon.png`

Tamano recomendado:

- logo principal: `512x512 px`
- favicon base: `64x64 px`
- margen interno de seguridad: `10%` por lado

Uso:

- header del sitio
- login
- sidebar admin
- portal privado

### `branding/heroes/`

Aqui van las imagenes grandes para portada o secciones principales.

Archivos sugeridos:

- `hero-home.jpg`
- `hero-solution.jpg`

Tamano recomendado:

- desktop: `1600x900 px`
- mobile adaptable: mantener zona segura central de `1200x700 px`
- margen visual libre: `8%` alrededor del contenido importante

Uso:

- pagina de inicio
- solucion
- marketing principal

### `branding/banners/`

Aqui van banners o piezas horizontales para paneles internos.

Archivos sugeridos:

- `admin-banner.jpg`
- `portal-banner.jpg`

Tamano recomendado:

- `1440x480 px`
- margen interno: `6%` horizontal y `10%` vertical

Uso:

- dashboard
- portal
- CTA internos

### `branding/avatars/`

Aqui van iconos o fotos de usuarios, equipo o perfiles.

Archivos sugeridos:

- `user-placeholder.png`
- `team-member-01.jpg`

Tamano recomendado:

- `400x400 px`
- margen interno: `12%`

Uso:

- perfiles de colaborador
- perfil cliente
- testimonios

## Formatos sugeridos

- logos: `PNG` o `SVG`
- fotos: `JPG` o `WEBP`
- ilustraciones UI: `PNG` o `WEBP`

## Regla general de calidad

- fondo transparente para logos
- resolucion alta para hero y banners
- no poner texto pegado al borde
- mantener peso razonable para web
